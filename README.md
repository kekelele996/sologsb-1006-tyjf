# 会议同传提示台

面向会议管理员和同传人员的现场提示台。后台准备内容与现场可见内容明确分离，支持实时队列、术语提醒、紧急通知以及断网手工录入。

## 功能

- 维护演讲顺序、发言人、语言方向、术语表和紧急通知。
- 自动接入现场文字并进入后传译队列；可手动模拟下一段。
- **中文位 / 英文位双轨独立**：两路各自记录确认、撤回、补译与术语提醒，互不覆盖。
- **上屏按语种分栏**：舞台字幕分中文 / 英文两栏，仅显示本语种已送达的确认内容；一边撤回（含撤屏）不影响另一边。
- **顺序核对**：自动比对两路对同一段的处理先后；出现交叉反转时列入“待值班主管核对”清单，相关未送达段落暂缓上屏，由主管“放行 / 驳回”。
- **推送与重试**：确认后进入本语种投递（排队 → 已上屏 / 失败）；失败可单条或整路重试，按投递批次去重，已送出的内容不会重复上屏。可开启“模拟推送故障”演练。
- 逐条补充遗漏、标记待跟进和清理重复提醒（补译按语种分开保存）。
- 基于字符二元组相似度检测重复内容；延迟超过 8 秒显示警告。
- 术语表支持高优先级、指定译法，术语提醒可分别发送给中文位 / 英文位并各自“已看到”确认。
- 紧急通知先保存后台，管理员明确发布后才进入现场可见区。
- 网络中断时继续手工录入本机暂存；恢复后合并并重新执行重复检查。
- 键盘优先：`J/K` 移动、`C` 中文位确认、`E` 英文位确认、`T/R` 分别向中文位 / 英文位发术语提醒、`N` 聚焦录入、`+/-` 调节字号。
- 浏览器本地持久化、撤销重做与字号偏好恢复。

## 行为测试

```bash
npm run test:behavior
```

纯 Node（esbuild 打包 + localStorage 垫片）断言：撤回隔离、双路补译 / 提醒、顺序核对挂起与放行、推送重试与去重。

## 技术栈

- SvelteKit、Svelte 5、TypeScript
- Tailwind CSS 3、Flowbite Svelte
- 浏览器 `localStorage`

## 本地开发

```bash
npm install
npm run dev
```

Vite 开发服务器监听 5173，仅属于开发环境；应用不定义宿主端口。

## 生产构建

```bash
npm install
npm run check
npm run build
```

静态产物位于 `build`，使用 `@sveltejs/adapter-static` 生成。

## Docker

```bash
docker build -t sologsb-1006 .
docker run --rm -p 10006:80 sologsb-1006
```

nginx 监听容器 80，并根据根端口表映射到宿主 `10006`。

## 数据说明

当前为纯前端离线演示，所有管理员配置、现场队列和暂存内容保存在当前浏览器。清理站点数据会移除本地记录。
